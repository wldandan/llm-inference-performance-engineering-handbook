# Chapter Review

## 总体评价

第 1 章已经收紧为“启动、调用、观察、留档”。读者先完成一次真实流式调用，再区分客户端事件与服务内部过程。正文不再逐节讲 Gateway、Queue、Prefill、Decode 和 KV Cache，符合 v1.0 大纲中“第一个 LLM 服务”的入门定位。

## 结构问题

- 已解决：原稿把生命周期、组件架构和模型机制提前展开，与第 2～4 章重复。
- 已解决：学习目标从六类内部机制压缩为四项可操作结果。
- 已解决：章节插图由 10 张压缩为 4 张，每张图都直接服务运行步骤或观察边界。
- 仍需完成：在课程指定 GPU 环境做一次端到端实跑并保存脱敏报告。

## 技术与术语问题

- 客户端首个非空内容 chunk 与服务端首 token 已明确区分。
- stream_chunks 被定义为客户端非空内容片段计数，不再暗示它等于 output_tokens。
- ttft_ms 被限定为客户端墙钟观察值，不在本章归因到 Prefill。
- Gateway 不再作为所有部署都必经的独立组件出现在开篇图中。
- Queue、Prefill、Decode 只作为后续章节路标出现，没有在本章讲机制。

## 内容缺口

- 发布前需要记录 Python、vLLM、驱动、GPU 和模型版本。
- 需要保存一次成功请求的脱敏 JSON 报告，供读者核对输出结构。
- 当前 Demo 会输出 ITL 和 tokens_per_second 等预览字段；正文已经说明它们不是本章的性能结论。

## 可删减内容

原稿中的 Gateway 入口、Queue 与 Scheduler、Prefill、Decode Loop、KV Cache 生命周期和资源回收独立小节已删除。相关内容分别由第 2 章生命周期、第 3 章架构、第 4 章模型机制及后续专项章节接手，不需要在第 1 章重复保留。
