## 已确认通过

- Part 1 只包含 Ch1～Ch5。
- Ch1 负责跑通与客户端观察，Ch2 负责真实生命周期证据。
- Ch3 使用 Ch1 的 30 个输入 tokens、256 个输出 tokens 和 254 个流式 chunks 约束机制解释，并明确 chunk 不等于 token 或 GPU 执行步。
- Ch3 的 GQA 和 temperature 边界正确；机制检查器只验证张量形状、采样候选和 KV Cache 事件。
- Ch4 以课程中真实 vLLM 单实例作为 Reference System；Router / Admission 是 Scale-out 可选职责，逻辑角色不等于已经证明的运行进程。
- Ch5 只从真实单请求报告读取可成立的指标，明确客户端首个内容 chunk、平均 chunk 间隔、请求输出速率和 GPU 瞬时快照的解释边界。
- 单请求报告不能推出 P50/P95/P99、稳定吞吐、Goodput 或容量上限。
- 合成输入均明确标注为机制或公式检查数据，不作为课堂主案例，也不形成 Benchmark 结论。
