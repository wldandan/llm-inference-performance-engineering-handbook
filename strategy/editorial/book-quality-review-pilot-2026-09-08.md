# 图书 / 课程项目质量审查报告（试点）

审查日期：2026-09-08  
审查对象：当前仓库中的课程设计、v1.0 大纲、30 章正文、7 个 Part 导读、Demo / Workshop 映射、章节评审文件、配套代码与无 GPU 自动化测试。  
审查结论：**不通过**。

## 1. 结论摘要

当前材料不能作为一套完整、可交付的 v1.0 图书 / 课程发布。最主要的阻断项不是局部措辞，而是权威大纲、正文、Part 导读、Demo 映射和评审结论使用了不同的章节体系：v1.0 大纲从 Ch8 起采用新结构，实际正文从 Ch8 到 Ch29 仍采用旧结构。由此造成课程承诺的 Benchmark、Profiling、RAG、Agent、多 GPU、MoE / PD 等内容没有出现在承诺的章节位置，正文、练习、Demo 和总结也无法按当前目录互相对应。

可确认的积极项：Ch1–Ch7 的正文、代码和章节边界相对完整；30 章均具备“学习目标、核心问题、Demo / 实验、练习 / 自检、总结”等栏目；本地 Markdown 图片和文件链接未发现缺失；298 个 SVG 均通过 XML 解析；排除一个依赖环境不兼容的服务测试目录后，149 项测试通过并有 14 项子测试通过。

但这些局部结果不足以覆盖目录错位、正文骨架化、证据不足和验收入口失效等 P0 问题。

## 2. 证据级别与严重程度

- **已证实问题**：可由当前仓库文件、自动化命令或权威一手资料直接复现。
- **合理疑问**：当前材料不足以确认正确性或可运行性，需要作者补充版本、原始数据或实验记录。
- **个人偏好**：不影响正确性和任务完成，仅涉及风格；本报告不把偏好作为阻断项。

严重程度：

- **P0 / 阻断**：会误导读者、破坏目录与内容对应、导致任务无法完成，或使发布结论不可信。
- **P1 / 重大**：显著影响教学闭环、事实可信度或材料可复现性。
- **P2 / 一般**：影响一致性、维护性或阅读体验，但不单独阻断交付。

### QA-010：关键性能数字缺少直接、限定范围的证据

- 问题位置：`content/ch16/ch16.md` 第 62、70 行。
- 问题类型：事实 / 引用 / 实验结论。

### QA-011：对 PagedAttention 的表述使用了不可证实的绝对结论

- 问题位置：`content/ch16/ch16.md` 第 40 行附近，“消除显存碎片”“让 KV Cache 显存利用率逼近理论值的关键机制”。

## 8. 可复用质量门（不绑定题材）

本试点采用的通用质量门适用于图书、课程与 Workshop：

1. **基线门**：存在项目 Brief，目标读者、范围、交付和权威来源唯一明确。
2. **对应门**：章节目标、正文、案例、练习和总结逐项对应。
3. **事实门**：数字、公式、代码、图表和结论能追溯到来源或实验；推断与偏好明确标注。
4. **任务门**：读者能按说明完成任务，提交物和判定标准明确。
5. **可运行门**：配套材料在声明环境中可重复运行，失败条件和降级路径清楚。
6. **一致性门**：术语、编号、链接、版本和跨章引用一致。
7. **发布门**：P0 为零，P1 有明确关闭计划；最终结论只能是通过、有条件通过或不通过。

任何项目都应以其自身 Brief 定义具体阈值；本报告中的 LLM、GPU、框架和章节编号仅是试点证据，不属于通用审查标准。
